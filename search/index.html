Cómo interpretar los resultados

Las respuestas directas son síntesis editoriales versionadas en Markdown, con criterios y fuentes. Si no existe una respuesta verificada, lo indicamos. La exploración adicional utiliza embeddings multilingües + BM25 + Reciprocal Rank Fusion; una coincidencia temática no equivale a una respuesta.

Las citas enlazan líneas de una versión inmutable en GitHub. El enlace abre GitHub solo cuando lo seleccionas. No se usa un modelo generativo.
